## Proposed protection

The existing admin communications routes did not provide an audited batch suppression that leaves consent unchanged. This PR adds a single super-admin route pinned to the reviewed target digest. It inserts only active, topic-wide `marketing` suppressions for the exact 117 destinations, preserving any existing suppression reason and all consent fields. The C04 importer uses an insert with conflict ignore for active suppressions, so this protection takes precedence. An `gp_import_run` audit row records the actor, source, classification and target hashes, and before/after counts. The fixed batch identity makes a replay read-only.

The proposed route has not been deployed or invoked against production. No import or send occurred in this session.
